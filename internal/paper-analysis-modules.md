# Paper Analysis Modules

Updated-At: 2026-09-05

## 使用方式

模块随核心主张启用，可以组合；材料类型不决定证据强度。阅读流程和完成标准以 `content/utility/paper-analysis-workflow.md` 为准。下表给出每类主张应追问的判别问题，答案写入对应机制、证据或局限，不另建重复检查表。

v3 每个关键结果共用 `证据定位`、`观察`、`判别性与局限`、`支持的最窄结论` 四个字段。关键条件可以写在这些字段或前文共享设置中。语义由人工自审核验，自动检查只验证结构；v2.1 历史字段 advisory 仅用于兼容，不再作为升级 v3 硬规则的路线。

## 按主张检查

| 模块 | 决定判断的问题 | 结论收缩的典型条件 |
| --- | --- | --- |
| `experiment` | 比较对象、数据、初始化、训练与推理预算、选择协议各固定了什么？干预改变几个变量？独立实验单位、重复次数、区间估计是否支持差异？ | 未匹配算力只能支持整个配置的比较；测试参与调参会影响泛化判断；单次最佳运行不能说明稳定优势。 |
| `system` | 实际数据与控制路径是什么？硬件、软件、精度、批量、并发、输入输出长度和冷热状态如何影响结果？吞吐与延迟的分母、测量窗口、资源归因和端到端边界是什么？ | FLOPs、字节估算与实际时间分别表达；内核收益不能直接外推到服务吞吐；排队、通信、预处理或离线训练未计入时说明成本边界。 |
| `theory` | 定义、量词、假设、参数区间与结论是否一致？关键引理如何连接？是存在性、可构造性、可学习性、渐近界还是有限样本保证？ | 构造存在不保证优化能找到；必要与充分条件不能互换；去掉关键假设的反例与理论到实践的映射缺口需要明确。 |
| `model-report` | 模型版本、参数口径、架构、训练阶段、数据、监督来源、评测配置和已披露成本能否对应？能力比较是否混入工具、搜索、推理预算或专用后训练？ | 缺少训练数据与配方时不能作结构因果归因；模型卡宣称、发布方评测与独立复现分别记录。 |
| `survey` | 综述的检索范围、截止时间、纳入与排除规则、分类轴与代表工作是什么？分类是否覆盖反例？结论依赖的工作是否被直接阅读？ | 作者选择的材料集合不能自动代表全领域；数量统计受来源和分类重叠影响；过时范围不能支持当前全局结论。 |
| `safety` | 威胁模型、攻击者访问与能力、目标、评测环境、成功判据、误报漏报及防御代价是什么？ | 沙箱成功不等于现实可利用；只测攻击成功而未测正常效用，不能判断防御可用性；披露不包含可直接滥用的操作细节。 |
| `docs` | 责任主体、适用版本、前置配置、可观察行为、失败路径和兼容边界是什么？声明与实际读取的实现是否一致？ | 文档承诺、只读代码推断与本地运行结果分别表述；只查一个版本不能宣布其它版本行为一致。 |

## 深读时的选择

LLM 强化学习主张涉及训练行为时，优先追踪采样策略、轨迹分组、优势或奖励、目标函数、梯度流、被更新对象与训练/推理差异。batch、context、KL、entropy、optimizer、token budget、判题器和 checkpoint 只要会改变机制或比较口径，就应记录已披露值或相邻缺口。用户要求复现时再系统补齐运行参数、依赖和未披露项。

模型报告的 `Model Summary` 采用 `Field | Value` 紧凑表格，适用字段及口径遵循 `AGENTS.md`。总参数与激活参数、模型与注意力隐藏维度、MoE 潜空间与单专家维度、专家总数与每 token 选中数及共享数分别记录。量化说明权重、激活值和量化感知训练状态。未披露写明，本地推导标明计算口径。

组合模块按主张分配证据。系统论文的算法等价性可以由证明支持，时延收益需要实测；同一结果不必复制两个模块表。只有一种证据时，明确它尚未支持的另一类主张。

## 人工验收正反例

以下是解释判别标准的示意，不是任何论文的实验事实：

- **实验**：两个配置同时改变算法和样本数，准确率更高。可以得出“联合配置在该协议下更高”，算法独立增益仍未识别；仅写“对照可比”不足以说明比较。
- **系统**：专家集合缩小并伴随时延下降，可以支持观测关联；硬件流量若由参数量估算，不能写成实测带宽减少，也不能排除内核形状变化。
- **理论**：给出满足假设的权重构造能证明存在性；声称训练会学到该解还需要优化或学习证据。
- **启发**：一个反例限制了原有判断的适用域，可以形成有边界的新认识；无需人为附加另一领域的应用。若提出迁移，则应写出目标条件和可能否定预测的观察。
- **资料不足**：只读到摘要时，结论可以归因于作者宣称；方法接口、数字口径和失败条件仍不能写成已经核验。
