## 跨论文关系

- `2603.00729` 新增 Qwen3-Coder-Next / agentic coding model report 节点。它基于 Qwen3-Next-80B-A3B-Base，使用 hybrid attention + MoE、80B total / 3B active、256K / 262K context，并把大规模 executable task synthesis、MegaFlow rollout、multi-template tool calling、SWE expert RL 和 expert distillation 写成 Qwen-Coder 专门报告。
- `2603.00729` 与 [2412.15115 Qwen2.5](/papers/2412.15115-qwen2-5-technical-report/)、[2505.09388 Qwen3](/papers/2505.09388-qwen3-technical-report/) 和 [2606.12370 Bebop](/papers/2606.12370-bebop-mtp-rejection-sampling-rl-training/) 构成 Qwen foundation-to-agentic-coding 系谱。Qwen2.5/Qwen3 提供 foundation model、long context、thinking control 和 agent/tool-use evaluation 基座；Bebop 处理 Qwen 内部 MTP rollout acceleration；Qwen3-Coder-Next 将训练重点转向 executable SWE environments、repo-level trajectories 和 tool-call robustness。

## 后续新增论文沉淀规范

详细流程见 [paper-analysis-workflow.md](/workflow/)，新增笔记使用 [paper-note-template.md](/template/)。

最低要求：

- 新增论文必须沉淀为独立 Markdown 文件。
- 新增论文必须更新本索引。
- 新增论文必须在对应笔记中分析作者与机构关系，并在 `data/authors.json` 中维护稳定作者事实。
- 阅读后的交流环节若产生有效修正、核心表述、指标清单或跨论文关系，必须回写对应笔记；影响索引判断时同步更新本索引。
- 若出现重复作者、同一实验室连续论文、主题演化、引用关系或方法复用，并且该关系能改变跨论文理解，必须在本索引中单独记录。
- 对技术博客、项目文档或工程报告，可使用稳定来源 ID 作为索引编号，并同样记录作者/机构、主题关系和跨材料关系。
- 面向站点展示的已存档论文链接统一使用 `/papers/<slug>/` 形式；工作流、模板、索引页面分别使用 `/workflow/`、`/template/`、`/archive/`。
