# 论文研究主线

First-Archived-At: 2026-07-16 19:51
Updated-At: 2026-07-17 18:40

本页说明研究主线目录的组织方式。当前快照覆盖 102 条归档材料，按 48 条细粒度研究路径组织方法演进；其中 41 条为正式主线，7 条为候选方向。逐篇论文入口继续由[论文索引](/archive/)提供，单篇阅读和证据审计方法见[阅读工作流](/workflow/)。

## 目录怎样组织

每条主线围绕一个可持续追踪的问题展开，例如“稀疏 Attention 的历史选择与执行”“长上下文训练的 Activation 重算与保留策略”或“RLVR 增益的 Reward、先验与 Harness 归因”。方法、系统、架构、训练目标、估计器与协议都可以成为方法节点。

一篇论文可以贡献多个节点，同一节点也可以进入多条主线。每条主线分别说明该节点在本问题中的前序约束和局部优化，因此多方面贡献可以完整保留。

八个较宽的方向现在作为横向 facet 使用：

| Facet | 覆盖范围 |
| --- | --- |
| 资源约束下的模型扩展 | 规模配比、训练状态、MoE、优化器与 Activation |
| 长历史的状态选择与访问 | Attention、KV、长上下文与 Agent 记忆 |
| 语义感知的推理与 Agent Runtime | 推测执行、工作流 IR、状态所有权与调度 |
| 可执行环境驱动的 Agent 能力 | 工具、环境合成、环境模型与多 Agent 编排 |
| Reasoning RL 的能力边界与探索 | 长 CoT、探索预算与能力支持集 |
| 从终局成败到局部信用与验证 | 过程监督、Verifier、信用分配与知识迁移 |
| 保持策略语义的分布式 RL 系统 | 数据流、异步训练、一致性与 Rollout 加速 |
| 优化压力下的奖励与证据完整性 | Proxy Reward、选择过优化、规则利用与监控 |

Facet 只提供横向观察角度，不形成父子层级。一条主线可以同时关联多个 facet。

## 正式主线与候选方向

正式主线满足以下任一条件：

1. 当前归档中已有至少两个相关方法节点。
2. 当前归档中已有一个方法节点，并存在一个高置信外部直接前序。外部节点需要规范来源、明确关系和至少一项认可度信号。

候选方向保留当前方法、证据缺口和升级条件。它们同样拥有独立详情入口，便于后续材料到来时延续稳定 ID。状态表达当前谱系完整度，不表示论文质量、会议等级或结论重要性。

## 方法关系怎样表达

关系性质与证据来源分别记录。每条关系先说明“方法之间发生了什么”，再说明“这项判断依据什么材料”。

| 关系性质 | 含义 |
| --- | --- |
| 直接继承 | 后续方法明确沿用前序方法或来自官方续作 |
| 问题响应 | 后续方法针对前序暴露的具体限制改变机制 |
| 组合复用 | 后续系统将已有机制接入新的算法或执行流程 |
| 并行路线 | 方法处理同一问题，但采用不同状态、计算或系统契约 |
| 反例修正 | 新证据限定或修订此前较强的解释 |

| 证据来源 | 使用边界 |
| --- | --- |
| 论文明确陈述 | 原论文直接描述继承、比较对象或目标问题 |
| 作者或官方续作 | 同一团队、官方报告或正式实现明确延续前序机制 |
| 机制与实验判断 | 根据公开方法、状态契约和实验形成的本地分析 |

时间只决定节点排列。关系边来自独立证据记录；无直接证据的同期方法保持并列。并行路线不生成方向箭头。

## 详情页包含什么

每条正式主线使用统一的六节结构：

1. 核心问题与范围
2. 演进概览
3. 方法继承表
4. 关键分歧与反例
5. 当前判断
6. 开放问题

演进图与方法表读取同一份节点和关系数据。图用于查看分叉、合流和跨线依赖；表格保留首次公开时间、前序方法、关系性质、前序问题、局部优化和证据来源。节点进入多条主线时，各详情页展示与该问题对应的解释。

Membership 记录节点在单条主线中的总体问题与贡献；当节点存在前序关系时，表格优先使用 relation context 中逐边记录的问题与优化。一个节点连接多个前序时，相关文案会带前序方法名，避免把不同关系合并成无法对应的段落。

## 归档状态与外部节点

方法节点区分三种归档状态：

- 独立归档：规范来源已有完整论文笔记。
- 综合材料内分析：方法已在一篇 composite 笔记中实质分析，规范来源仍指向原论文、项目或官方实现。
- 未归档外部节点：用于补充高置信直接前序，只保留名称、首次公开时间、规范来源、认可度信号和关系证据。

外部节点后续升级为完整论文笔记时保持稳定节点 ID。综述、模型卡、时间线和纯边界材料可以不创建方法节点，仍会以证据、反例、边界或综合材料的角色进入语料覆盖。

## 证据边界

当前快照反映截至 2026-07-17 已完成审计的材料，论文集合偏重长上下文、LLM RL、Agent 系统与前沿模型报告。它提供问题导航和方法关系，不代表机器学习领域的均匀抽样。

首次公开时间优先采用规范来源的公开日期；来源只提供月份时保留到月。会议日期、归档日期和后续修订日期不会替代首次公开时间。

跨论文实验通常没有对齐模型、数据、硬件、prompt、采样预算、工具协议和 runtime。方法表适合比较问题定义与机制变化，具体性能和结论边界仍应回到对应论文笔记核验。

## 更新方式

研究主线采用手动快照，不配置定时自动发现。每周需要刷新时，由维护者主动检查快照之后新增或修订的论文，先完成单篇来源、机制、证据、局限和跨论文关系审计，再更新受影响的方法节点、关系、主线状态与当前判断。

更新时优先保持稳定的主线 ID、节点 ID 和证据定位。新增数量本身不会产生关系边，也不会自动把候选方向升级为正式主线。
