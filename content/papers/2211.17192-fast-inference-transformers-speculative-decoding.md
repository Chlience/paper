## 一句话结论

这篇论文把 speculative execution 推到随机采样场景：小 draft model 先自回归生成一批候选 token，大 target model 一次并行验证这些前缀，并用截断到一的 target-to-draft 概率比决定接受位置，再由 residual distribution 校正拒绝位置，从而在无需改模型、无需重训且保持 target 输出分布不变的前提下，把大模型串行 decode 的目标调用数降低到每步平均生成多个 token。

## 阅读目标与判断边界

本笔记关注：

1. speculative sampling 为什么能保持输出分布严格等于 target model。
2. 接受率为什么等于 $\sum_x \min(p(x),q(x))=1-\mathrm{TV}(p,q)$。
3. speedup 的必要条件、成本模型和实验设置。
4. 它与后续 MTP、Bebop TV loss、GLM-5.2 / Seer rollout acceleration 的关系。

判断边界：

- 论文证明的是 lossless stochastic sampling 的算法正确性；实际系统是否完全一致还取决于 logits 标准化、数值精度、sampler 实现和 batch/kernel determinism。
- walltime 实现只在 T5-XXL / T5X 上报告，batch size 为 1，硬件为单 TPU-v4；GPT-like 和 LaMDA 主要报告 $\alpha$，没有完整 walltime benchmark。
- 论文面向 off-the-shelf approximation model；后续 draft model 训练、EAGLE/Medusa/MTP heads、tree verification 和 RL rollout 场景属于后续发展。

## 论文脉络

### 1. 研究问题、背景和价值

自回归 Transformer 生成 $K$ 个 token 需要 $K$ 次串行 target model forward。模型越大，单步 forward 越慢，KV cache 和权重读取也越容易受内存带宽与通信限制。已有压缩、量化、稀疏、early exit 和 adaptive computation 方法能降低成本，但通常需要改结构、重训或改变输出。

作者抓住两个观察。第一，生成中的不同 token 难度不同，很多 token 可以被更小模型预测到。第二，大模型 decode 在许多部署中受 memory bandwidth / communication 限制，设备上仍有额外算力可用。于是可以用额外并行算力换串行步数：小模型先猜，大模型一次验证多个前缀。

### 2. 已有解决方案与不足

Blockwise Parallel Decoding 已经有“一次预测多个 token，再由 base model 验证最长前缀”的结构，但主要适用于 greedy decoding，且需要额外训练自定义 heads，目标是保持任务质量。Shallow Aggressive Decoding 也用类似 draft-verify 思路，但适合输入输出高度相似的任务，如 grammatical error correction。

这篇论文补齐的关键是 stochastic sampling。它把 temperature、top-k、nucleus、argmax 等都抽象成对 logits 处理后的标准分布采样，然后在任意 $p,q$ 之间构造一个 exact correction rule，使最终采样仍服从 target 分布 $p$。

### 3. 作者可能的思考路径

作者的思路可以重建为：

1. 大模型每步都串行运行，低难 token 上存在明显浪费。
2. 小模型可以给出便宜候选，但直接采用会改变分布。
3. 若 target model 能并行评估 draft prefix，则一次 target call 可以给出多个位置的 $p_i$。
4. 问题收敛为：给定 target distribution $p$ 与 draft distribution $q$，如何尽可能多接受来自 $q$ 的样本，同时保证最后输出等价于从 $p$ 采样。
5. 使用 maximal coupling / residual correction 的思路：重叠部分 $\min(p,q)$ 直接接受，draft 多出的部分用拒绝概率移除，target 剩余质量 $p-\min(p,q)$ 由 residual distribution 补采。
6. 接受率自然等于分布重叠质量 $\sum_x \min(p,q)$，也就是 $1-\mathrm{TV}(p,q)$。这成为后续 draft model 训练目标讨论的理论入口。

### 4. 核心假设或切入点

- target model 可以在一次并行调用中计算 $prefix, prefix+[x_1], ..., prefix+[x_1,\ldots,x_\gamma]$ 的 next-token distribution。
- approximation model $M_q$ 的单步成本 $c$ 远低于 target model $M_p$，且系统有足够并发资源让 $\gamma+1$ 个 target positions 并行执行。
- 采样方式先被标准化为分布 $p(x)$ 和 $q(x)$；exactness 针对标准化后的分布成立。

### 5. 单 token speculative sampling

目标是从 target distribution $p(x)$ 采样。算法先从 draft distribution $q(x)$ 采样 $x$。若 $q(x)\le p(x)$，直接接受；若 $q(x)>p(x)$，以概率

$$
1-\frac{p(x)}{q(x)}
$$

拒绝该 token。等价地，接受概率是：

$$
\alpha(x)=\min\left(1,\frac{p(x)}{q(x)}\right).
$$

拒绝后，从 residual distribution 重新采样：

$$
p'(x)=\operatorname{norm}(\max(0,p(x)-q(x))).
$$

### 6. 多 token speculative decoding step

Algorithm 1 的流程是：

| Step | 计算 | 作用 |
| --- | --- | --- |
| Draft | $M_q$ 自回归采样 $x_1,\ldots,x_\gamma$ | 便宜地产生候选前缀 |
| Verify | $M_p$ 并行计算 $p_1,\ldots,p_{\gamma+1}$ | 一次 target call 验证所有候选位置，并准备 bonus token |
| Accept prefix | 对每个 $i$ 用 $r_i\sim U(0,1)$ 检查 $r_i \le p_i(x_i)/q_i(x_i)$ | 接受最长连续前缀 |
| Correct / bonus | 若 $n<\gamma$，从 $\operatorname{norm}(\max(0,p_{n+1}-q_{n+1}))$ 采样；若 $n=\gamma$，从 $p_{\gamma+1}$ 采样 | 拒绝时校正第一个失败位置；全接受时多生成一个 target token |

每次调用至少返回 1 个 token，最多返回 $\gamma+1$ 个 token。

### 7. 正确性证明

令

$$
\beta=\sum_x \min(p(x),q(x)).
$$

拒绝后的 residual distribution 为：

$$
p'(x)=\frac{p(x)-\min(p(x),q(x))}{1-\beta}.
$$

于是最终输出某个 token $x'$ 的概率为：

$$
\begin{aligned}
P(x=x')
&=P(\text{accepted},x=x')+P(\text{rejected},x=x')\\
&=\min(q(x'),p(x'))+\left(p(x')-\min(q(x'),p(x'))\right)\\
&=p(x').
\end{aligned}
$$

所以无论 $q$ 质量如何，输出分布都等于 $p$。差别只体现在 acceptance length 和系统开销。

### 8. 接受率与 TV distance

论文定义：

$$
D_{LK}(p,q)
=\sum_x\left|p(x)-\frac{p(x)+q(x)}{2}\right|
=\frac{1}{2}\sum_x |p(x)-q(x)|.
$$

这就是常用的 total variation distance。由

$$
D_{LK}(p,q)=1-\sum_x \min(p(x),q(x))
$$

可得单步接受率：

$$
\beta
=\mathbb{E}_{x\sim q}\left[\min\left(1,\frac{p(x)}{q(x)}\right)\right]
=\sum_x \min(p(x),q(x))
=1-D_{LK}(p,q).
$$

后续 Bebop / LK losses / TV loss 之所以把 draft training 目标转向 overlap 或 TV，基础关系就在这里。

### 9. 期望生成 token 数与 speedup

若简化假设每步 acceptance rate i.i.d.，且 $\alpha=E(\beta)$，一次 speculative decoding step 的期望输出 token 数为：

$$
E[\#\text{tokens}]
=\frac{1-\alpha^{\gamma+1}}{1-\alpha}.
$$

令 $c$ 为 $M_q$ 单步时间 / $M_p$ 单步时间，则 walltime improvement factor 为：

$$
\frac{1-\alpha^{\gamma+1}}{(1-\alpha)(\gamma c+1)}.
$$

若 $\alpha>c$，存在某个 $\gamma$ 能带来加速；取 $\gamma=1$ 时加速因子至少为：

$$
\frac{1+\alpha}{1+c}.
$$

这说明 speculative decoding 的核心系统条件是：draft 足够便宜，且 draft-target overlap 足够高。

### 10. 算术量与 memory access

论文明确区分 latency 和 total arithmetic operations。Algorithm 1 会并行跑 $\gamma+1$ 个 target positions，因此并发算术量上升；若有拒绝，部分 target 位置计算会被丢弃。令 $\hat{c}$ 为 $M_q$ 单步算术量 / $M_p$ 单步算术量，total arithmetic operations 增加因子为：

$$
\frac{(1-\alpha)(\gamma\hat{c}+\gamma+1)}{1-\alpha^{\gamma+1}}.
$$

但 target 权重和 KV cache 可以在一次并行 verification 中读取，memory access 可按平均输出 token 数降低。这解释了为什么该方法适合 memory bandwidth / communication bound 的推理系统。

### 11. 结论链条

1. 自回归 decode 的串行 target call 是大模型 inference 主要瓶颈。
2. 小模型或简单 heuristic 可以便宜地产生多个候选 token。
3. 通过 speculative sampling，可以在任意 $p,q$ 下保持最终输出分布等于 $p$。
4. 接受率等于 $1-\mathrm{TV}(p,q)$，因此 draft-target overlap 直接决定平均接受长度。
5. 若 $M_q$ 足够便宜，且系统有额外并发，减少 target 串行调用数能转化为 walltime speedup。
6. T5-XXL 实测在单 TPU-v4、batch size 1 上获得 2.3x-3.4x speedup；GPT-like、T5、LaMDA 的 $\alpha$ 测量显示不同规模 draft 都能产生可用 overlap。

## 关键实验/定理

### 结果 1：speculative sampling 的 exactness

- 设置：任意离散分布 $p(x)$ 与 $q(x)$，从 $q$ 先采样，按 $\min(1,p/q)$ 接受，拒绝后从 residual distribution 采样。
- Baseline：直接从 $p$ 采样。
- 指标：最终 token 分布。
- 结果：最终输出概率为 $\min(p,q)+p-\min(p,q)=p$。
- 解读：这是 lossless speculative decoding 的核心保证；draft model 质量只影响效率。

### 结果 2：接受率等于 $1-\mathrm{TV}(p,q)$

- 设置：单步 speculative sampling。
- Baseline：常规 target sampling 无 draft；常规 rejection sampling 作为 appendix 对照。
- 指标：接受概率 $\beta$。
- 结果：

$$
\beta=\sum_x \min(p(x),q(x))=1-D_{LK}(p,q).
$$

- 解读：论文中的 $D_{LK}$ 等价于 TV distance。后续 TV loss 直接优化 acceptance 的理论来源就是这条式子。

### 结果 3：T5-XXL walltime speedup

- 设置：T5-XXL 11B 为 target；T5-small 77M、T5-base 250M、T5-large 800M 为 approximation model；任务为 WMT EnDe 与 CNN/DailyMail；batch size 1；single TPU-v4；同时测试 argmax sampling (`temp=0`) 与 standard sampling (`temp=1`)；使用现有 checkpoints；baseline 为 T5X 标准实现。
- Baseline：T5X autoregressive decoding。
- 指标：$\gamma$、$\alpha$、walltime speedup。
- 结果：

| Task | Draft $M_q$ | Temp | $\gamma$ | $\alpha$ | Speed |
| --- | --- | ---: | ---: | ---: | ---: |
| EnDe | T5-small | 0 | 7 | 0.75 | 3.4x |
| EnDe | T5-base | 0 | 7 | 0.80 | 2.8x |
| EnDe | T5-large | 0 | 7 | 0.82 | 1.7x |
| EnDe | T5-small | 1 | 7 | 0.62 | 2.6x |
| EnDe | T5-base | 1 | 5 | 0.68 | 2.4x |
| EnDe | T5-large | 1 | 3 | 0.71 | 1.4x |
| CNNDM | T5-small | 0 | 5 | 0.65 | 3.1x |
| CNNDM | T5-base | 0 | 5 | 0.73 | 3.0x |
| CNNDM | T5-large | 0 | 3 | 0.74 | 2.2x |
| CNNDM | T5-small | 1 | 5 | 0.53 | 2.3x |
| CNNDM | T5-base | 1 | 3 | 0.55 | 2.2x |
| CNNDM | T5-large | 1 | 3 | 0.56 | 1.7x |

- 解读：T5-small 通常速度最高，因为它在 $\alpha$ 与 draft cost $c$ 之间取得较好平衡。draft 更大时 $\alpha$ 上升，但 $c$ 也上升，最终 speedup 可能下降。

### 结果 4：跨模型 $\alpha$ 测量

- 设置：对 GPT-like 97M / T5-XXL 11B / LaMDA 137B 的不同 draft model 测量 $\alpha$；每个 setting 使用 target 生成的 10K tokens 估计。
- Baseline：unigram / bigram trivial model；小 Transformer / T5 / LaMDA draft。
- 指标：$\alpha=E[\sum_x\min(p,q)]$。
- 结果摘录：

| Target | Draft | Sampling | $\alpha$ |
| --- | --- | --- | ---: |
| GPT-like 97M | GPT-like 6M | t=0 | 0.88 |
| GPT-like 97M | GPT-like 6M | t=1 | 0.89 |
| T5-XXL EnDe | Bigram | t=0 | 0.20 |
| T5-XXL EnDe | T5-small | t=1 | 0.62 |
| T5-XXL CNNDM | T5-small | t=1 | 0.53 |
| LaMDA 137B | LaMDA 100M | t=1 | 0.57 |
| LaMDA 137B | LaMDA 2B | t=1 | 0.71 |
| LaMDA 137B | LaMDA 8B | t=1 | 0.74 |

- 解读：小两到三个数量级的 draft model 仍可得到 0.5-0.9 的 overlap。简单 bigram 在 EnDe 上 $\alpha\approx0.2$，若 $c\approx0$ 且 $\gamma=3$，也能带来约 1.25x 的理论 speedup。

## 证据链强度评估

### 强证据

- 单步 speculative sampling 的 correctness proof 非常直接，输出分布严格还原到 $p$。
- 接受率等于 $\sum_x\min(p,q)=1-\mathrm{TV}(p,q)$，推导清晰，后续大量工作沿用这一关系。
- T5-XXL 实验包含真实 walltime 对比，并给出 $\gamma,\alpha,c$ 的理论/实测对照。

### 中等强度证据

- “两数量级更小 draft 通常效果最好”由 GPT-like、T5、LaMDA 的 $\alpha$ 与 T5 walltime 支撑，证据范围仍属于有限架构覆盖。
- n-gram / copy heuristic 可作为 negligible-cost draft 的想法有实验线索，但论文只给出有限示例。
- 可变 $\gamma$ / oracle $\beta$ 可进一步提升最多约 60% 的分析是理论上界，未实作。

### 需要谨慎的推论

- batch size 1 的单 TPU-v4 结果不能直接代表现代高吞吐 serving。continuous batching、prefix cache、tree attention、paged KV、heterogeneous vocab、logprob kernel 和 scheduler 会改变成本模型。
- i.i.d. $\beta$ 假设只是简化；真实 acceptance 和位置、上下文难度、采样温度、domain、draft 自身 exposure bias 都有关。
- total arithmetic operations 增加在 compute-bound 场景会抵消 latency 收益。
- exactness 依赖相同 sampling standardization。若 target 和 draft 的 temperature/top-k/top-p/grammar mask 或 tokenization 不一致，需要额外校正。

## 本地讨论补充

### 1. 讨论收敛点

- stochastic speculative decoding 中 target 并不先采一个“标准答案 token”再与 draft 比较。target 计算完整分布 $p$，draft token 以 $\min(1,p/q)$ 概率被接受。
- “严格等于下一个 token 才认可”对应 greedy / temperature=0 场景的退化理解；标准随机 sampling 语境中是概率接受。
- TV loss 的后续动机来自本文：如果 rejection sampling 的接受率就是 $1-\mathrm{TV}(p,q)$，则直接优化 TV overlap 会比只优化 CE/KL 更贴近 acceptance 目标。

### 2. 修正后的理解

- 论文中的 $D_{LK}$ 可以视作 total variation distance：$D_{LK}(p,q)=\frac{1}{2}\|p-q\|_1$。
- 后续 Bebop 使用 TV loss 训练 MTP heads，解决的是 draft training objective 与 rejection sampling acceptance 的对齐问题；这篇论文本身不训练 draft，也不提出 TV loss。
- target-only / exact-match 式 speculative decoding 和 probabilistic rejection sampling 要分开讨论；前者更接近 greedy verifier，后者保持完整 sampling distribution exactness。

### 3. 后续复验指标

- 每个 task / temperature / position 的 $\alpha_i$ 分布，而非只看平均 $\alpha$。
- walltime speedup、target serial calls、draft cost $c$、total arithmetic operations、memory bandwidth、KV cache read/write。
- batch size、continuous batching、paged KV、prefix cache、tree verification 下的有效 $\gamma$ 与 acceptance length。
- sampler consistency：target/draft logits preprocessing、temperature/top-p/top-k/grammar mask、tokenization、randomness 和 floating-point path。

## 主要启发

- 解码加速可以通过减少串行 target calls 实现，额外并发算力和更高算术量可以换取更低 latency。
- draft model 的评价指标应包含 acceptance overlap。单纯 perplexity 或 CE/KL 只间接反映 speculative decoding speedup。
- 保证输出分布不变需要 residual correction；只看“draft 与 target 是否一致”的解释会漏掉随机采样中的概率接受机制。
- 对 RL rollout acceleration 来说，MTP / speculative decoding 的收益需要同时记录 entropy、TV overlap、draft cost、verification rule 和系统调度。

## 局限

1. T5 walltime 实验规模有限：batch size 1、single TPU-v4、T5X；没有覆盖现代 GPU serving、continuous batching 和多用户 workload。
2. GPT-like 与 LaMDA 部分主要报告 $\alpha$，没有完整端到端 latency benchmark。
3. 算法降低串行步数，但会增加并发算术量；compute-bound 或缺少 spare compute 的场景收益有限。
4. beam search 只在 appendix 中给出可能方案，性能和正确性细节未充分展开。
5. lenience 能提高接受率，但会改变输出分布；本文主要结论依赖 lenience disabled 的 strict mode。
6. 没有公开 official reviews，无法吸收 reviewer 对 baseline、实现和泛化边界的具体质疑。
